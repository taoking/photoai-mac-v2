# 信息架构与交互

> 状态：v0.6（2026-11-20）。v0.3 按原型第一轮反馈修订；v0.4、v0.5 记录 M2、M3 原生实现的细节（§4.1、§4.2、§7）；v0.6 加入观看体验（§3.4、§3.5、§4.3）。产品规则见 [产品定位与目标](产品定位与目标.md)。

## 1. 设计原则

1. **一个窗口、一条主路径。** 插卡 → 导入 → 按时间浏览 → 打星 / 打标签 → 按条件筛出 → 归进收藏夹 → 导出。其他功能都是这条路上的辅助。完整的例子见 §3.0。
2. **看图在主区域里切换，不叠覆盖层。** 网格、单张、比较是同一块内容区的三种视图，切换时网格的滚动位置和选择都保留。
3. **键盘优先。** 选片的全部动作都能单手完成，每个键只在一处实现。
4. **概念少。** 用户只需要理解：照片、卷、收藏夹、星级、标签、Pick/Reject。

## 2. 术语表

界面上只用这些词，代码里用对应的英文名。

| 界面用词 | 含义 | 英文名 |
| --- | --- | --- |
| 照片 | 一次拍摄，可能包含 RAW 和 JPEG 两个文件 | Photo |
| 卷 | 一张卡或一块盘 | Volume |
| 位置 | 照片在某个卷上的路径 | Location |
| 收藏夹 | 手动归集的一组照片，只存引用 | Collection |
| 星级 | 0–5 星，表示好坏 | Rating |
| 标签 | 用户自定义的分类，如人像、风景、经典；每个标签有一种颜色和一个快捷键 | Label |
| Pick / Reject | 留用 / 淘汰标记；第三种状态是“未标记” | Flag |
| 无卷关联照片 | 所有位置都已失效、被隐藏的照片 | Orphan |

**星级和标签分工**：星级回答“好不好”，标签回答“是哪一类”。两者可以组合筛选，比如“经典 + 5 星”。v1 的颜色标签是自由文本，v2 改成预先定义好的几个标签，打的时候一个键、筛的时候一下点选。

**去掉的概念**（v1 有、v2 不要）：单独的“收藏”（心形）、自由文本颜色标签、备注、智能选片、相似清理、连拍分组。

**词不能混用**：“筛选”只指按条件过滤；挑照片的动作叫“选片”。

## 3. 主窗口

### 3.0 典型场景：一次旅行的选片

旅行回来，一张卡上有 1,800 张照片。

1. 在侧栏点“卡 A”，排序选“拍摄时间 新→旧”。
2. 按空格进入单张视图，打开自动前进（⇪）。每张看一眼：按 `1`–`5` 打星，按 `6`–`9` 打标签（比如 `6` 经典、`7` 人像、`8` 风景），不要的按 `X`。一张可以同时有星级和多个标签。
3. 回到网格，在筛选条里点“经典”和“★5”，只剩下 63 张。刚改过的照片不会突然从结果里消失，点“刷新结果”或改筛选条件时才重新筛。
4. `⌘A` 全选，`⇧B` 新建收藏夹“新疆 · 经典”并加入。
5. 在侧栏点这个收藏夹，去掉几张不想要的（`⌫`），再补几张。
6. `⌘E` 导出原文件到精修目录。

- `▦ ▢ ◫`：网格 / 单张 / 比较，三种视图。
- `●` 在线、`○` 离线。

### 3.0.1 顶部尽量薄（原型第一轮反馈）

用户反馈：中间顶部的框太大，影响浏览；单张时顶部框可以不要。改为：

| 区域 | 网格视图 | 单张 / 比较视图 |
| --- | --- | --- |
| 工具栏 | 一行 | 一行；`F` 专注模式时隐藏 |
| 标题行 | 一行 36 px：标题 · 卷在线状态 · “N 张无副本”（点击做清卡检查）· 搜索条件 · 筛选摘要 · 计数 · “⋯” | 隐藏 |
| 筛选条 | 一行；`\` 或工具栏“筛选”收起 | 隐藏 |
| 照片信息 | 检查器 | 浮在画面底部的信息条，鼠标不动 2 秒淡出 |

- 卷的容量、扫描目录、上次扫描时间放进标题行的悬停提示和“⋯”菜单；重新扫描、清卡检查、改名、移除卷都在“⋯”菜单里。
- 筛选条只放常用条件（星级、标签、Pick / Reject / 未标记）；文件类型和“无标签”收进“更多 ▾”。“刷新结果”只在有照片已不符合条件时出现，“清除”只在有条件时出现。
- 筛选条收起时，生效的条件以“筛选：★5+ · 经典 ✕”显示在标题行，点它展开筛选条，点 ✕ 清除。
- 专注模式：单张或比较视图里按 `F`，隐藏侧栏、检查器、工具栏，只留照片和胶片条；`F` 或 `Esc` 退出。

### 3.1 侧栏

| 分组 | 内容 | 说明 |
| --- | --- | --- |
| 图库 | 全部照片、最近导入 | “最近导入”按导入批次列出，插完卡最常用 |
| 时间 | 年 → 月 → 日 | 主路径；默认展开最近一年的最近一个月 |
| 卷 | 所有在用的卷 | 显示在线状态和张数；右键：重新扫描、改名、清卡检查、移除卷 |
| 收藏夹 | 所有收藏夹 | 显示张数；可新建、改名、删除（删收藏夹不删照片） |
| 人物 | 人物网格入口 | 后台识别完成后才有内容 |
| 地点 | 地名列表 | 只在开启地点功能后出现 |

已移除的卷和无卷关联照片都不出现在侧栏。

### 3.2 工具栏

只放 7 个控件：

1. **搜索框**：全局搜索，见 §6。
2. **筛选**：打开网格上方的筛选条，见 §3.3.1。
3. **排序**：拍摄时间（新→旧 / 旧→新）、文件名。
4. **视图切换**：网格 / 单张 / 比较。
5. **缩略图大小**：滑块。
6. **导出**：打开导出面板，见 §7。
7. **检查器**：显示 / 隐藏。

评分、标记、加入收藏夹这些动作不放工具栏，用键盘、右键菜单和“照片”菜单完成。

### 3.3 网格

- 缩略图**按原始比例完整显示**，不裁切，竖拍照片也能看清构图。
- 按拍摄时间排序时，每天一个分组标题，显示日期、星期、张数。
- 每张照片单独一格，不做连拍折叠。
- 格子上的角标：星级、标签色点、Pick / Reject、`RAW+JPG`；卷离线时加一个小的离线标记。
- 单击选中，⇧ 点击连选，⌘ 点击加选；双击或空格进入单张视图。

#### 3.3.1 筛选条

网格上方一行，常用条件一下点选，不用打开菜单：

```text
★ ≥1 2 3 4 5 · 正好│ ●经典 ●人像 ●风景 ●… │ Pick Reject 未标记 │ 更多▾ │ 刷新结果 │ 清除
```

- 星级、标签、标记各点一下即生效，再点一下取消；同类里多选取“或者”，不同类之间取“并且”。例如“经典 或 人像”并且“5 星”。
- “更多”里是不常用的条件：RAW / JPEG / RAW+JPEG、相机、镜头、没有标签。
- **筛选结果在你打星、打标签的过程中保持不变**，改过的照片暂时留在原地，只是角标更新。点“刷新结果”或改筛选条件时才重新筛。这样不会出现“刚打完星，照片就从眼前消失”的情况。
- 侧栏的每一项（某张卡、某个收藏夹、某一天）各自记住自己的筛选条件，切走再切回来还在。

#### 3.3.2 标签管理

- 设置里定义标签：名字、颜色、顺序。默认给 9 个空位，前四个预填“经典 / 人像 / 风景 / 人文”，可改。
- 顺序决定快捷键：第 1–4 个对应 `6`–`9`，全部 9 个对应 `⌥1`–`⌥9`。
- 一张照片可以有多个标签。
- 删除一个标签只是把它从所有照片上去掉，照片本身不受影响。

### 3.4 单张视图

```text
┌────────────────────────────────────────────────────────┐
│ ← 网格   DSC01926 · ★★★★☆ · ●经典 · Pick   12 / 214  ⓘ │
├────────────────────────────────────────────────────────┤
│                                                        │
│                     大图（1600 预览）                     │
│                                                        │
├────────────────────────────────────────────────────────┤
│ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢ ▢   胶片条（当前结果）                    │
└────────────────────────────────────────────────────────┘
```

- 显示本机的 1600 预览，卷离线也能看。
- 在一张照片上停约 0.3 秒、原片所在卷在线时，后台按屏幕尺寸读原图，读好后换掉预览，接着读后一张、前一张，所以连续往后翻时下一张一出来就是原图。快速翻页时中间的照片不读。卷离线、文件读不到时安静地留在预览，不改位置状态（设计稿 §4.1）。信息条上写“原图”“预览”或“离线”。
- 背景、照片边框和投影、四周留白在“显示”菜单里选（设计稿 §6），单张、比较、放大共用。
- `Z` 放大到 100%：原文件所在卷在线时读原文件，离线时只能放大预览，并提示需要插哪个卷。
  - M3 实现：一个图像像素对一个屏幕像素；读好原图之前先放大预览，顶部写着“100% · 正在读取原文件…”，读好后换成“100% · DSC01066.JPG（卡名）”。
  - 也可以**单击照片**放大到 **50%**、以单击的位置为中心（照片边缘不滚进画面）；适合窗口已经不小于 50% 时放大到 100%。放大后单击（不拖动）回到适合窗口，按住拖动或用触控板滚动平移。
  - 任意比例：`⌘+` / `⌘−` 按“适合窗口 / 50% / 100% / 200%”换档，`⌘0` 回到适合窗口；触控板捏合可到任意比例（最大 400%），捏到比适合窗口还小就回到适合窗口。顶部写着当前比例，如“150% · DSC01066.JPG（卡名）”。
  - 放大时 ← → 翻页仍保持 100% 和同一个位置，方便比较连拍的清晰度；只留当前这张的原图，不占太多内存。
  - 读原图优先用 JPEG（真实卡上 112–175 ms，RAW 要 0.6–1.5 秒）；JPEG 的长边不到 RAW 的九成（小尺寸 JPEG）时才用 RAW。
  - 读的时候发现原片已不在（卷挂着、文件没了）：位置改为历史，提示“原片已不在「卡名」上”；没有其他副本的照片移到“无卷关联照片”，焦点落到相邻的照片。
- `I` 显示或隐藏参数浮层。

### 3.5 比较视图

- 选中 2–4 张后按 `C`，并排显示。
- 缩放和平移在所有格子之间同步。M3 实现：`Z` 让所有格子同时放大到 100%，各自读原图；拖动任一格，其他格跟着移到照片上的同一位置；单击一格把它设为焦点格。`⌘+` / `⌘−` 和捏合改变的比例也同步到所有格子。
- 方向键切换焦点格，打星和标记作用于焦点格。
- 两张比较时，`⇧P` 把焦点格标为 Pick、另一张标为 Reject。

## 4. 键盘

全部快捷键只在菜单命令里定义一次，网格、单张、比较三种视图共用。文本框获得焦点时，单键快捷键自动让位给输入。

| 键 | 动作 |
| --- | --- |
| ← → | 上一张 / 下一张 |
| ↑ ↓ | 网格中换行 |
| 1–5、0 | 设置星级、清除星级 |
| 6–9 | 切换前四个标签（再按一次取消） |
| ⌥1–⌥9 | 切换第 1–9 个标签 |
| ⌥0 | 清除所有标签 |
| P / X / U | Pick / Reject / 清除标记 |
| 空格 | 网格 ↔ 单张 |
| C | 比较 |
| F | 专注模式（单张、比较） |
| \ | 显示 / 隐藏筛选条 |
| Esc | 退出放大 / 退出专注模式 / 回到网格 |
| Z | 放大到 100% / 回到适合窗口 |
| ⌘+ / ⌘− | 放大一档 / 缩小一档（适合窗口 / 50% / 100% / 200%） |
| ⌘0 | 适合窗口 |
| I | 参数浮层 |
| B | 加入上一次用过的收藏夹 |
| ⇧B | 加入收藏夹…（弹出选择或新建） |
| ⇪（Caps Lock） | 自动前进开关：打星、打标签、标记后自动跳到下一张 |
| ⌘A | 全选当前结果 |
| ⌫ | 在收藏夹里：从收藏夹移除（照片本身不受影响） |
| ⌘Z / ⇧⌘Z | 撤销 / 重做星级、标签、标记、加入或移出收藏夹 |
| ⌘F | 聚焦搜索框 |
| ⌘E | 导出… |
| ⌘1–⌘3 | 网格 / 单张 / 比较 |

设置页有一张速查表，从同一份定义生成。

### 4.1 原生实现（M2）

- 命令表在 `Sources/PhotoAIApp/KeyCommands.swift`：菜单（图库、照片、显示、帮助）、键盘处理和“帮助 → 快捷键…”速查表都从它生成。
- 按键先经过一个本地事件监视：主窗口里没有在输入文字时由它执行命令；正在输入文字（文本框、改名框、新建收藏夹的名字）时，单键直接交给文本框，菜单抢不到；`⌘A`、`⌘Z` 在文本框里是文字的全选和撤销。
- Caps Lock 开着时字母按小写认，`⇧` 另外看：`P` 是 Pick，`⇧P` 才是“焦点格 Pick、另一张 Reject”。
- 已经是这个值时再按一次（如 3 星再按 3）不写库、不进撤销，但照样自动前进。
- 撤销记录只在本次运行内，见[设计稿 §7.1](设计稿.md)。
- `Z` 和比较视图的同步缩放在 M3 做（要读原文件），见 §4.2。

### 4.2 原生实现（M3）

- `Z`、`⌘E` 加进同一张命令表；菜单“显示 → 放大到 100%”，“图库 → 导出…”，工具栏多一个“导出…”按钮，收藏夹标题行的“⋯”里有“导出这个收藏夹…”。
- Esc 按顺序：先退出放大，再退出专注模式，最后回到网格。
- 单击照片放大到单击的位置，比例 50%（对用户“照片无法放大”反馈的补充，2026-11-20 用户确认，原型同步加上）。

### 4.3 原生实现（观看体验）

- `⌘+`（`⌘=`、`⌘⇧=` 都认）、`⌘−`、`⌘0` 加进命令表，菜单“显示”里还有“背景”“照片细边框和投影”“四周留白”。
- 捏合交给 `NSScrollView` 自带的缩放；画布按一比一摆，比例就是它的 magnification。

## 5. 卷

### 5.1 插卡导入

1. 插入一个没见过的卷，软件弹出提示：“检测到新卷 Untitled（128 GB）”，选项为“添加…”和“忽略”。不点就什么都不做。
2. 添加时给卷起名，再选扫描哪个文件夹：存储卡默认 `DCIM`；外置盘每次手动选。
3. 扫描开始后照片按批次出现在网格里，进度显示在状态栏。
4. 已知的卷插上时自动重扫，只处理新增和变化的文件，并续扫上次没扫完的目录。扫描中途拔卡不会让照片消失：没扫完的目录保留上次的结果。

### 5.2 卷详情

点侧栏里的一个卷，内容区显示这个卷的照片，上方是卷信息条：

标题行显示卷名、在线状态和“N 张缺副本”；“⋯”菜单的第一行显示收录与离线预览就绪两种进度，例如“已收录 3,412 · 离线预览就绪 3,108”，以及没扫完的目录数。

```text
│                                                      │
│ [只看已打星/Pick/收藏夹]  缺副本照片网格……                │
│                                                      │
│ [补副本到…]                    [取消]  [仍然移除卷…]       │
└──────────────────────────────────────────────────────┘
```

- 只有全部文件已核实、预览全部就绪，才显示“可以清空这张卡”。
- “补副本到…”：保留原文件名，冲突时换新子目录，复制后校验，完成后重扫目标；失败的文件单独列出。
- “仍然移除卷”再确认一次，确认框里重复三类数量，说明这些照片会从常规列表隐藏、预览保留。

## 7. 导出

一个导出面板，三个选择：

1. **范围**：所选照片 / 当前结果 / 某个收藏夹。
2. **文件**：RAW / JPEG / 两者都要。
3. **目录结构**：平铺 / 按收藏夹分子文件夹 / 保持原目录。

面板底部列出需要哪些卷在线；离线卷上的照片列出来，可以只导出在线部分。导出只复制，目标存在同名文件时自动改名，绝不覆盖。

M3 实现的细节：

- **默认范围**：选中多张时是所选照片；在收藏夹里是这个收藏夹；否则是当前结果。收藏夹在单选下面的菜单里换。
- **文件**：“只导出 RAW”时没有 RAW、或 RAW 的所有在线位置都读不到，改导出 JPEG（反过来一样）；“两者都要”时只删了其中一个文件的照片导出还在的那个。
- **目录结构**：“按收藏夹分子文件夹”在范围是某个收藏夹时只有这一个文件夹；范围是所选或当前结果时，照片在几个收藏夹里就复制进几个文件夹，不在任何收藏夹里的放进“未归入收藏夹”。“保持原目录”是 `卷名/原来的目录/`。文件夹名里的 `/`、`:` 换成 `-`。
- **同名**：目标已有同名但内容不同的文件时，改名为 `DSC01926 (2).ARW`；同一张照片的 RAW 和 JPEG 用同一个编号，配对不被拆开。目标已有同名、内容逐字节相同的文件时不再复制，记为“已有相同”，所以中断后再导出一次就是续传。
- **其他**：保留原文件的修改时间；目标默认 `~/Pictures/精修`，记住上次选的目标、文件和目录结构；“需要的卷”随卷插拔即时更新，“跳过离线卷”的勾选保持不变；没勾时按钮是“插入离线卷后导出 N 张”且不可点。
- **进行中**：状态栏显示“导出 12 / 300 张 · 1.2 GB”和“取消”。结束后弹出结果：导出多少张、多少个文件，改名、已有相同、从其他位置读、改用另一种格式、位置改为历史、跳过离线的数量，没导出的文件逐个列出原因，可以“在 Finder 中显示”。
- **读不到**：每个文件依次尝试所有在线的现存位置；都读不到才算失败。卷挂着、文件不在的位置改为历史，界面随即刷新；目标写不进去（写满、没有权限）时整个导出停下，报告还有多少张没导出。

## 8. 无卷关联照片

从菜单“图库 → 无卷关联照片…”打开一个单独的窗口：

- 按曾经所在的卷分组，组内按日期排列；已移除的卷只在这里出现。
- 标出已打星、已 Pick、已进收藏夹的照片。
- 可以单张、多选或整组删除，确认一次后删除照片记录、缩略图和预览。

## 9. 后台任务

状态栏一行显示正在进行的后台任务：扫描、预览生成、人物、OCR、地名。点“详情”打开任务面板，每类任务可以暂停 / 继续，并显示进度和失败数。选片时的交互请求永远优先于后台任务。

- 状态栏的后台任务行在没有任务时隐藏。
