## 1. 定位

一个只给自己用的本机选片工作台，同时是所有导入过照片的预览档案：

- 记住每张照片在哪张卡、哪块盘上；
- 在本机永久留一份预览，卡和盘拔掉、清空以后照样能浏览和选片；
- 选好的照片归进收藏夹，再导出原文件去别处精修。

不做调色修图；从不改动、移动、删除卡和外置盘上的文件。

## 2. 规模与前提

- 只有自己用；约 5 万到 10 万条；主要是相机照片。
- 多张存储卡、多块外置盘，经常插拔。
- 全新开始，不迁移 v1 数据；不开 App 沙盒。
- 预览放内置盘：480 缩略图 + 1600 预览，10 万张约 44 GB。

## 3. 核心概念

| 概念 | 规则 |
| --- | --- |
| 照片 | 一次拍摄。名字不同一定不是同一张；名字相同时按拍摄时间认定，没有拍摄时间按文件大小。同编号、同拍摄时间的 RAW 和 JPEG 合成一张，预览优先用 JPEG 生成 |
| 卷 | 一张卡或一块盘，按卷 UUID 识别，用户起名。状态：在线、离线、已移除 |
| 位置 | 照片在某个卷上的路径。现存：卷在用且文件还在；历史：卷已移除或文件已不在 |
| 星级 | 0–5，表示好坏 |
| 标签 | 用户自定义的类别（经典、人像、风景……），有颜色和快捷键；一张可以有多个 |
| Pick / Reject | 留用 / 淘汰标记 |
| 收藏夹 | 手动归集的照片引用，一张可以在多个收藏夹里 |

不做：心形收藏、自由文本颜色标签、备注、连拍分组、相似 / 重复清理建议、调色、视频。

## 4. 可见性与删除

- 照片至少有一个现存位置才出现在常规列表、搜索、收藏夹和命令行里；否则只出现在“无卷关联照片”窗口。离线但没移除的卷算有关联。
- 移除卷（清卡）、重扫发现文件不在：位置变成历史位置，**不删照片、预览、评分和收藏夹**。
- 常规界面没有删除照片的入口。真正删除只在“无卷关联照片”窗口里做，已移除的卷也只在这里出现。
- 删掉的照片重扫时会重新导入，不做忽略名单。

### 4.1 在线 / 离线与原片被手动删除

- **在线 / 离线只看卷有没有挂载**（按卷 UUID 对上），不逐个检查原片。挂载和卸载由系统通知推送，几乎不耗资源；逐个检查 10 万个文件在存储卡上要几十秒，不做。
- 因此在 Finder 里手动删掉原片后，软件**暂时不知道**，照片照常显示（预览在本机）。软件不监听文件变动，也不主动定期扫描。发现的时机只有这些：
  1. 重新扫描，包括已知的卷插上时的自动重扫；
  2. 导出或 100% 放大时读不到原片：这一张单独报错，其余照常导出；
  3. 清卡检查时现场核对副本（见 §5）。
- 发现后：这个位置改为历史位置。照片还有其他现存位置就照常显示；没有就进入“无卷关联照片”。星级、标签、收藏夹、预览都保留。文件放回去再重扫，照片恢复可见。
- RAW + JPEG 只删了其中一个文件时，照片仍然可见，导出时只导出还在的那个。
- 移除后的卷重新插上算新卷；没被删掉的照片会对回原记录并恢复可见。

## 5. 清卡

1. 列出这张卡上没有其他现存副本的照片，标出其中已打星、已 Pick、已进收藏夹的。
   - 副本信息来自上次扫描，可能过时。**在线卷上的副本当场核对文件是否还在**（只查这些文件，很快），发现不在的按没有副本计算；**只在离线卷上的副本**无法核对，单独列出并注明“按上次扫描结果”。
2. 可以直接把这些照片复制到别的盘。
3. 不论检查结果如何，都可以确认后继续移除。

## 6. 主要界面

- 一个窗口：侧栏（图库、时间、卷、收藏夹、人物、地点）+ 内容区 + 检查器 + 状态栏。
- 内容区顶部尽量薄：一行 36 px 的标题行（标题、卷在线状态、“N 张无副本”提醒、筛选摘要、计数、“⋯”更多操作）+ 一行筛选条。筛选条可用 `\` 或工具栏“筛选”收起，收起后生效的条件以摘要显示在标题行。
- 单张、比较视图收起标题行和筛选条；单张视图的信息条浮在画面底部，鼠标不动 2 秒后淡出，打星、打标签时短暂出现。`F` 专注模式再隐藏侧栏、检查器和工具栏。
- 内容区三种视图：网格 / 单张 / 比较，在同一块区域里切换，不叠覆盖层；切换时保留滚动位置和选择。
- 网格：缩略图按原比例完整显示；按天分组；每张单独一格。
- 筛选条：星级、标签、Pick / Reject 点一下即生效；同类“或者”、不同类“并且”；打星过程中结果保持不变，点“刷新结果”才重新筛；侧栏每一项各自记住筛选条件。
- 导出面板：范围（所选 / 当前结果 / 收藏夹）× 文件（RAW / JPEG / 两者）× 目录结构（平铺 / 按收藏夹 / 保持原目录）；只复制、不覆盖。
- 后台任务（扫描、预览、人物、OCR、地名）在状态栏显示进度，没有任务时隐藏；交互请求永远优先。

## 7. 键盘

| 键 | 动作 |
| --- | --- |
| ← → ↑ ↓ | 切换照片 / 网格换行 |
| 1–5、0 | 星级、清除星级 |
| 6–9 | 切换前四个标签 |
| ⌥1–⌥9、⌥0 | 切换第 1–9 个标签、清除所有标签 |
| P / X / U | Pick / Reject / 清除标记 |
| ⇪ | 自动前进开关 |
| 空格 / C | 网格 ↔ 单张 / 比较 |
| F | 专注模式（单张、比较） |
| \ | 显示 / 隐藏筛选条 |
| Esc | 退出专注模式 / 回到网格 |
| B / ⇧B | 加入上一次的收藏夹 / 选择或新建收藏夹 |
| ⌫ | 在收藏夹里：移出收藏夹 |
| ⌘A、⌘E、⌘F、⌘Z | 全选、导出、搜索、撤销 |

快捷键只定义一处；文本框获得焦点时单键快捷键让位给输入。

## 8. 典型场景（原型必须走通）

单卡 → 按时间倒序 → 边看边打星、打标签 → 筛选“经典 + 5 星” → 全选 → 新建收藏夹 → 在收藏夹里增减 → 导出原文件。

## 9. 外部接口

- 命令行工具 `photoai`：按文件名、去扩展名的文件名或编号（含范围）批量打星、批量加入或新建收藏夹，供 Claude skill 调用。
- 编号命中多张时取拍摄时间最晚的一张，输出里列出被跳过的和匹配不到的。只匹配可见照片。
- 默认在软件关闭时使用。软件按字段写入、窗口获得焦点时检查外部改动；其余副作用接受。

## 10. 后台分析

- 人物、OCR：导入后异步进行，人脸特征向量入库。
- 地点：Apple 反向地理编码（免费、需联网），坐标按约 1 公里网格缓存；默认关闭。
- Apple Photos 来源：之后的版本再加。
