# 观看体验验收（M3 之后，V-1–V-4）

> 分支 `viewing-experience`（从合并了 M2、M3 的 `main` 分出），记录日期 2026-11-20。对照 [计划 · M3 之后](../计划.md) 逐项记 **PASS / NOT RUN / BLOCKED**，附命令和输出。
> 机器：Apple Silicon（MacBook Air，内置 60 Hz Retina 屏），macOS 27.3，Xcode 27.0，Swift 6.4。真实照片：M1 导入的索尼 A7C II 卡（exFAT，USB 读卡器），2,148 组 ARW + JPG。

## 结论

用户反馈的四项都做完了，原型和原生软件一起改：

- **V-1** “显示”菜单：背景深灰（默认）/ 黑 / 中灰 / 白，照片细边框和投影，四周留白窄 / 宽；单张、比较、放大共用，记住设置。
- **V-2** `⌘+` / `⌘−` 按“适合窗口 / 50% / 100% / 200%”换档，`⌘0` 适合窗口；触控板捏合任意比例（最大 400%）；比较视图同步；角上显示比例。
- **V-3** 单张视图停 0.3 秒、卷在线时按屏幕尺寸读原图换掉预览，再读后一张、前一张；离线或读不到时留在预览，**不**改位置状态。
- **V-4** 照片尺寸以生成预览的文件为准；已有的库启动时按缩略图校正一次，真实库改了 1,266 张。

自动测试 60 项、原型场景 83 项、软件里观看场景 **38 项**、导出场景 48 项 PASS。M2 典型场景 68 项 PASS、2 项 FAIL，`main` 上一样失败，见第 5 节。

**NOT RUN：** 用户本人走查（挑背景默认值、捏合手感、换原图后看得出清楚多少、单击放大要不要留）；真实的触控板捏合手势（软件里只验了捏合之后的比例同步和显示，手势本身由系统的 `NSScrollView` 处理）；外接显示器、非 Retina 屏。

新增 `PreviewTests` 两项：

- `dimensionsFollowPreviewSource`：同一张照片的 ARW（3:2）和 JPG（16:9），预览用 JPG 生成后照片尺寸是 2400×1350。把修改临时去掉时这一项失败（`ready.width == 2400 && ready.height == 1350`），证明测得到问题。
- `oldLibraryDimensionsAreCorrectedOnce`：把一张照片的尺寸改回 3:2，校正后回到 16:9，竖拍的不动；再改回去、再校正一次，返回 0（做过就不再做）。

## 7. 合并后的修正（2026-11-20，分支 `viewing-fixes`）

PR #5 合并后用户回复：“对的当时效果不太好，按不太好做很正确；单击照片放大功能很好，不过比例调小一些改为50%；另外排查一下查看大图时，切换图片，在下面那行小图附近会出现像重影一样的蓝色框 并不是选中的那张小图蓝色框”。

| 项目 | 结果 |
| --- | --- |
| 单击照片放大到 50%（适合窗口已不小于 50% 时到 100%），`Z` 仍是 100% | PASS（导出场景、原型） |
| 单击靠边时画面中心停在能到的最近处，想看的位置不被视图出现时的滚动改掉 | PASS（导出场景） |
| 单张视图翻页后胶片条里只有焦点那一格有蓝框 | PASS（截图前后对比） |
| 用户本人走查 50% 的手感、蓝框是否还出现 | NOT RUN |

**蓝框重影的原因：** 单张视图叠在网格上面（网格一直留着，切回来位置和选择都在），胶片条没有底色。网格跟着焦点滚动，选中那一格的蓝框和“RAW+JPG”角标会从胶片条的空隙里透出来，位置随翻页变，看起来像重影。改为胶片条用窗口底色。

验证：M2 典型场景里加了一张“翻过 20 张之后”的截图（`m2-single-turned`）。同一个库副本、同一步，改之前胶片条焦点格右边有一个浅蓝色的框，还透出网格的角标和星级；改之后只有焦点格的蓝框。

**单击放大的位置：** 改成 50% 后，导出场景的“画面中心在单击的位置”第一次跑失败了：单击 (0.25, 0.75)，画面中心却到了 (0.518, 0.80)。加调试输出后看到：放大视图刚出现、大小定下来时，系统会挪动可视区域，代码把这一下当成用户在平移，把想看的位置改掉了。100% 时恰好没碰上。改为可视区域大小变了（刚出现、窗口缩放）不算平移，回到想看的位置；捏合中照旧回报。另外，50% 时照片可能只比窗口大一点，单击靠边的地方没法摆到正中，场景改为核对“能到的最近处”，并单独核对想看的位置还是单击处。

$ PHOTOAI_LIBRARY_DIR=<工作目录>/lib-m3 PHOTOAI_SCENARIO=export PHOTOAI_EXPORT_DIR=<工作目录>/export \
    PHOTOAI_SCENARIO_BACKUP_DMG=<工作目录>/backup-b.dmg .build/PhotoAI-v2.app/Contents/MacOS/PhotoAIApp
