# 开发文档

给接手开发的人（或新开的 Claude 会话）看。使用说明在上一级：[安装与部署](../安装与部署.md)、[功能说明](../功能说明.md)。

## 先读

- [交接](交接.md)：现在在哪一步、下一步、代码地图、怎么跑验收、最容易做错的规则。
- [迭代](迭代.md)：1.0.0 之后的待办（`B-<n>`）、迭代（`I-<n>`）和版本。**后续所有改动都从这里开始。**

## 设计（`设计/`）

| 文件 | 内容 | 什么时候改 |
| --- | --- | --- |
| [设计稿](设计/设计稿.md) | 最终结论汇总，**以它为准** | 任何设计变更 |
| [产品定位与目标](设计/产品定位与目标.md) | 产品规则的细节与理由、v1 的经验 | 规则变更时 |
| [信息架构与交互](设计/信息架构与交互.md) | 界面、键盘、筛选条、各窗口线框 | 界面变更时 |
| [数据模型](设计/数据模型.md) | 表结构、照片身份、可见性、写入规则 | 数据变更时 |

设计稿和细节文档有冲突时，以设计稿为准，并把细节文档改过来。

## 过程记录（`记录/`）

| 文件 | 内容 | 什么时候改 |
| --- | --- | --- |
| [计划](记录/计划.md) | M1–M6 的范围、验收标准、性能目标 PF-1…PF-12、进度记录 | 只在进度记录加行 |

| [审查/](记录/审查/) | 外部审查报告及处理结果 | 有新审查时 |

## 原型（`原型/`，已冻结）

```sh
open docs/原型/index.html      # 浏览器直接打开，不联网，数据只在内存里
docs/原型/tests/run.sh         # 无界面 Chrome 走一遍典型场景（需要 Google Chrome）
```
