## 1. 图标

`Scripts/make-icon.swift` 用 CoreGraphics 画 1024 的图（深蓝圆角方底、两张叠着的照片、前面一张是日落山景、右下一颗金色的星），`Scripts/make-icon.sh` 转成各个尺寸并打成 `Resources/AppIcon.icns`。改图标就改脚本再跑一次，不用设计软件。

`Scripts/build-app.sh` 把 `AppIcon.icns` 放进 `Contents/Resources`，`Info.plist` 加 `CFBundleIconFile = AppIcon`。之前 Dock 里是灰色的通用图标，是因为 `.app` 里没有图标。

核对：`lsregister -f .build/PhotoAI-v2.app` 后用 `NSWorkspace.shared.icon(forFile:)` 取这个 `.app` 的图标，渲染出来就是新图标。

## 2. 检查器

改成从上到下：

1. **导航器**（只在单张视图放大时）：整张照片的小图，白框框出正在看的部分，框外压暗；点或拖动小图，画面跟过去；框贴着照片的边，不出照片。下面写当前比例。比较视图不显示（各格同步平移，框和单张一样，但用户只要单张）。
2. **直方图**：红绿蓝叠加、白线是亮度；按 480 缩略图算（RAW 的缩略图是相机内嵌的 JPEG，和相机屏幕上的直方图一样），长边缩到 320 数像素，几毫秒。高光溢出（任一通道到 255）、暗部死黑（三个通道都是 0）超过 0.5% 时下面一行提示。
3. **拍摄参数一行**：焦距、光圈、快门、ISO，等宽数字（原来在“参数”一行里）。
4. **选片**：星级、标记、标签、收藏夹。
5. **文件**：文件名、格式、拍摄时间、相机、镜头、尺寸。
6. 识别、现在在、预览（不变）。

不影响流畅度的做法：

- 直方图在一张照片上停 0.12 秒才算，在后台线程算，记下最近 300 张；打星不改照片编号，不重新算。
- 导航器的框大小由放大的视图报上来，只在比例或窗口大小变了时才报，平移时不报；导航器只有自己读平移中心，平移时检查器的其他部分不重画。

## 3. 流畅度（改前、改后）

`Scripts/test/inspector-pf.sh <工作目录>`：真实库副本，后台分析关，检查器开着（默认），同一台机器。改前是只加了图标的代码。

| 项目 | 改前 | 改后 |
| --- | --- | --- |
| PF-2 网格滚动 600 帧，主线程 | 中位 1.14 ms，95% 1.57 ms，超 16 ms 0 帧 | 中位 1.40 ms，95% 1.94 ms，超 16 ms 0 帧 |
| PF-6 打星，每 40 ms 一次 1,000 次 | 中位 12.6 ms，95% 16.1 ms | 中位 12.0 ms，95% 14.9 ms |
| PF-7 翻页，同上 | 中位 12.5 ms，95% 16.0 ms | 中位 11.8 ms，95% 14.8 ms |
| PF-6 打星，每 450 ms 一次 150 次 | 中位 32.6 ms，95% 40.5 ms | 中位 33.5 ms，95% 40.7 ms |
| PF-7 翻页，同上 | 中位 32.3 ms，95% 40.2 ms | 中位 33.1 ms，95% 40.4 ms |

都在波动之内。每 450 ms 一次时每张都会算直方图（停留超过 0.12 秒），PF-6 也没变。按人的节奏打星比快速连打慢（约 33 ms 对 12 ms）是已知的 P-1，改前就是这样，记在[迭代](../../迭代.md) B-3。
