# PhotoAI 命令行

用 `photoai` 命令改 PhotoAI 照片库里的星级和收藏夹。只用下面三个命令，不要用 `sqlite3` 直接改库，也不要用 `dev-` 开头的命令（那是开发验收用的）。

| 命令 | 做什么 |
| --- | --- |
| `photoai find <匹配项>…` | 找照片，不改任何东西 |
| `photoai rate <0-5> <匹配项>…` | 打星；`0` 是去掉星级 |
| `photoai collect "<收藏夹名字>" <匹配项>…` | 加入收藏夹；没有叫这个名字的就新建一个 |

## 匹配项

- 文件名：`DSC01926.ARW`（文件名和扩展名都要对上，不分大小写）
- 去掉扩展名的文件名：`DSC01926`
- 编号（文件名里最后一段数字）：`1926` 或 `01926`
- 编号范围（两头都算）：`1926-1950`。起点不能大于终点：相机编号从 9999 绕回 1 时拆成两段，如 `9990-9999 1-10`
- 可以写多项，用空格或逗号隔开：`photoai rate 5 1926-1950 1960,1962 DSC02001`

规则：

- RAW 和 JPEG 是同一张照片，一起打星、一起进收藏夹。
- 只匹配软件里看得到的照片；“无卷关联照片”匹配不到。
- 一个编号或名字命中多张时（编号循环，比如几年前和今年都有 DSC01926），只取**拍摄时间最晚**的一张，其余列在“跳过”里。想改旧的那张，请用户在软件里改。
- 收藏夹名字要完全一样（区分大小写）。有两个同名收藏夹时命令会报错，请用户先在软件里改名。

## 怎么用

1. 用户的说法有歧义（比如不确定是编号还是名字、范围是否绕回）时，先跑 `photoai find` 看匹配到哪些，再改。
2. 跑 `rate` 或 `collect`。输出先列改了哪些照片（`→ ★5` 表示从什么改成什么，`原本就在` 表示已经在收藏夹里），然后是“跳过”和“没有匹配到”。照片多于 100 张时只列前 100 张。
3. 告诉用户结果：改了几张；**有跳过或没匹配到的一定要说出来**，没匹配到的编号会合并成一段段（如 `1930、1933-1935`）。

退出码：`0` 有匹配到的照片；`2` 一张都没匹配到（什么都没改）；`1` 参数写错或打不开库（看错误输出）。

## 软件开着时

命令行默认在软件关闭时用，开着也可以：错误输出里会有“提示：PhotoAI 正开着……”，命令照样执行。转告用户：切回软件窗口后界面才会刷新，软件里的撤销记录会清空。

## 换库

环境变量 `PHOTOAI_LIBRARY_DIR` 指向另一个库的目录。只在用户明确要求时才设置；平时不设，用的就是软件的库。
